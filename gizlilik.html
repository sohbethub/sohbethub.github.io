Gizlilik Politikası — Megerse Yukleme

Son güncelleme: 25 Kasım 2026

"Megerse Yukleme", Meğerse YouTube kanalının (@megerse_tv) sahibinin kendi bilgisayarında çalıştırdığı kişisel bir yükleme aracıdır. Uygulama yalnızca kanal sahibinin kendi Google hesabıyla kullanılır.

Hangi verilere erişilir?

Uygulama, kanal sahibinin izniyle YouTube Data API üzerinden yalnızca şu işlemleri yapar: kanal sahibinin kendi ürettiği videoları Meğerse kanalına yüklemek, başlık, açıklama, etiket, kategori ve yayın zamanını ayarlamak, video kapağı eklemek ve yüklemenin doğru kanala yapıldığını doğrulamak için kanal adını okumak.

Veriler nerede saklanır?

Google'ın verdiği erişim izni (OAuth token) yalnızca kanal sahibinin kendi bilgisayarında saklanır. Uygulamanın bir sunucusu yoktur; hiçbir veri üçüncü kişilere aktarılmaz, satılmaz, reklam için kullanılmaz ve başka kullanıcılardan veri toplanmaz.

Google API Hizmetleri Kullanıcı Verileri Politikası

Uygulamanın Google API'lerinden aldığı bilgilerin kullanımı, Sınırlı Kullanım şartları dahil olmak üzere Google API Hizmetleri Kullanıcı Verileri Politikası'na uygundur. Uygulama ayrıca YouTube Hizmet Şartları'na ve Google Gizlilik Politikası'na tabidir.

İzni geri alma

Verilen erişim izni istenildiği zaman Google hesabı izinleri sayfasından geri alınabilir.

İletişim

Privacy Policy — Megerse Yukleme

Last updated: November 25, 2026

"Megerse Yukleme" is a personal upload tool run on their own computer by the owner of the Meğerse YouTube channel (@megerse_tv). It is used only with the channel owner's own Google account.

Data accessed

With the owner's consent, the app uses the YouTube Data API only to upload the owner's own videos to the Meğerse channel; set title, description, tags, category and publish time; set thumbnails; and read the channel name to verify uploads go to the correct channel.

Storage and sharing

The OAuth token is stored only on the channel owner's own computer. The app has no server; no data is shared with third parties, sold, used for advertising, or collected from other users.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account permissions.
